# 🍄 Mario Database Project

This repository contains the complete PostgreSQL database workshop dump for the **Mario Database** project.

## 📌 Project Overview
This project is built using PostgreSQL to practice relational database concepts, including:
- Designing relational database schemas
- Setting Primary Keys, Foreign Keys, and Unique constraints
- Querying and inserting structured relational data
- Exporting database dumps using `pg_dump`

## 🎓 Source & Course Details
- **Course**: [freeCodeCamp Relational Database Certification](https://www.freecodecamp.org/learn/relational-database/)
- **Platform**: freeCodeCamp (CodeAlly / Bash Environment)
- **Author**: [Hamza Shah](https://github.com/hamzads077-ds)
